# Structure Learning Layer

Research-only layer for market-structure scoring.

It does not trade live, does not use API keys, and does not modify strategy logic by itself. The layer reads a normalized trade CSV and scores every candidate trade using only trades that happened before the candidate entry time.

## Goal

The previous `trade_quality_score` layer showed that a confidence score can separate strong trades from weak trades on the sample dataset.

This layer adds a second dimension: **structure quality**.

It tries to answer:

```text
Which market-structure contexts actually worked recently?
Which contexts should be traded, watched, or skipped?
Should countertrend targets be compressed?
```

## Input

Required CSV columns:

```text
symbol,side,entry_time,exit_time,entry,stop,exit,r_mult
```

Optional columns used when available:

```text
setup_type,trend_context,volatility_regime,structure_type,kind,source
```

If optional columns are missing, the layer uses deterministic research fallbacks so sample tests can still run. Real validation should use real structure/context columns generated by the future market-data/strategy runner.

## Learning method

For each trade:

1. Use only the previous `lookback_days` of history.
2. Build a structure key:

```text
side | setup_type | trend_context | volatility_regime | structure_type | risk_bucket
```

3. Find matching historical trades.
4. If exact history is too small, fallback to broader structure keys.
5. Score the context using:

```text
sample size
profit factor
average R
winrate
max loss streak
```

6. Assign decision:

```text
TAKE
WATCH
SKIP
```

## Output

```text
results/structure_learning_summary.csv
results/structure_learning_decision_compare.csv
results/structure_learning_breakdown.csv
results/structure_learning_scored_trades.csv
```

The full scored-trades file is useful as an artifact. The summary, comparison, and breakdown files are small enough to commit for quick review.

## Current sample result

Using the deterministic sample runner trades:

```text
ALL trades:   PF 1.0762 | winrate 47.31% | avg R 0.0407
TAKE only:    PF 1.6616 | winrate 57.23% | avg R 0.2869
WATCH:        PF 1.4848 | winrate 55.18% | avg R 0.2203
SKIP:         PF 0.6683 | winrate 36.88% | avg R -0.2122
```

This is not proof of live profitability. It only proves that the research layer can separate better and worse structural contexts on the sample dataset.
